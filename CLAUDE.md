# R Package Development Workflow

<!-- R package for habit tracking and behavioral analysis -->

## Tech Stack

- **Language**: R (>= 4.0.0)
- **Core Tools**: devtools, usethis, roxygen2, testthat (>= 3.0.0)
- **Code Quality**: lintr, styler
- **Version Control**: Git + GitHub Actions

## Project Structure

```
habit-tracker/
├── R/                   # R source code
├── tests/testthat/      # Unit tests
├── man/                 # Documentation (auto-generated by roxygen2)
├── .claude/
│   ├── PRD.md          # Product requirements
│   └── reference/      # Detailed guides and conventions
├── DESCRIPTION         # Package metadata
└── NAMESPACE           # Exports (auto-generated)
```

## Core Development Workflow

```r
# Load package interactively
devtools::load_all()     # Ctrl+Shift+L

# Update documentation
devtools::document()     # Ctrl+Shift+D

# Run tests
devtools::test()         # Ctrl+Shift+T

# Check package
devtools::check()        # Ctrl+Shift+E
```

## Code Conventions

- **Naming**: `snake_case` for functions and variables (see `.claude/reference/r-style-guide.md`)
- **Assignment**: Use `<-` (not `=`)
- **Documentation**: roxygen2 comments for all exported functions
- **Testing**: testthat with >80% coverage, TDD approach preferred
